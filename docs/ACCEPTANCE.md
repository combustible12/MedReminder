# MedReminder V1.0 验收记录

状态：可安装预发布版已发布。6 项 JVM 测试、Android API 28 / 35 各 5 项功能测试、最终签名包安装启动检查全部通过。

## 构建与安装包

- Kotlin / Compose / Room 原生 Android 项目，Android 8.0 及以上。
- JVM 规则测试：6 项通过。
- Release APK 已构建，约 1.5 MB；固定 RSA 签名、APK v2 签名验证和源码 SHA-256 绑定检查通过。
- 最终流水线：[Android 构建与验收](https://github.com/combustible12/MedReminder/actions/runs/39350952515)。

## 尚未验证的部分

- 没有连接实体手机，荣耀、iQOO 等厂商后台/电池管理、自启动策略和长时间锁屏提醒未真机验证。
- 手机重启后提醒恢复已实现，但尚未完成重启恢复的端到端测试；系统回收进程后的提醒也未单独验证。
- 系统强行停止应用、关机、禁用后台运行时不保证提醒送达。
- 系统相册的各厂商选择器与所有图片格式未逐一真机测试；本地复制、保存重开和应用内大图查看已纳入自动化验证。

因此发布为个人使用预发布版，不将上述未验证项目称为已验收。
