## 1.0.25 便签删除联动与模块入口修正（待发布）

便签内删除某个药品时，会同时删除当天所有卡片、所有时段中的同一药品，并重新安排受影响卡片的提醒；药品库资料和既有用药时长历史保留。底部四个入口始终保持原布局：便签页加号添加卡片，药品库和用药时长页加号均添加药品。药品库与用药时长双向使用同一份药品资料；从这两个页面新增药品都不会自动放进便签。便签新增药品会同步创建药品库资料和用药时长卡片。顶部更新按钮在便签、药品库、用药时长三个主页面均显示。药品库点药品直接进入编辑，不再经过资料中转页。发布改为仓库 Actions Secrets 保管原签名、由 `release/ready.json` 一键构建和发布，聊天环境不再需要持有本地签名文件。

精简用药时长卡片，移除重复的“开始日期 / 结束日期 / 时长”说明行及其占用空隙，日期和时长数值直接显示在药品名称下方。搜索、一药一卡、自动记录、历史时段和手动补录功能保持不变。
