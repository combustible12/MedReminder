MedReminder 1.0.0 个人使用预发布版

- 自由卡片、大类、条目，支持编辑、删除和排序。
- 白底浅色圆角卡片，名称与每次用量优先显示。时间、规格可留空，留空隐藏。
- Room 本地数据库、药品复用、独立用量、多段使用历史和本地图片。
- 大类每日提醒，通知中显示药名和用量。支持重启、时区变更和升级后恢复调度。
- 删除首页安排保留药品档案，删除药品档案前二次确认。

自动化验收：JVM 规则测试、Android API 28 / 35 模拟器数据库和界面测试。请以本次 Actions 的实际测试报告为准。

未经过实体手机验证：荣耀/iQOO 等厂商后台管理、实体手机重启与长时间锁屏提醒。系统强行停止应用、关机或禁用后台运行时，Android 不能保证提醒送达。安装后请授予通知和精确闹钟权限，并允许后台运行。

无账号、无网络权限、无打卡和统计功能。所有数据在本机；卸载或清除应用数据会删除资料。
