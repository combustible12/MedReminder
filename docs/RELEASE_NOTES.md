## 下一版 操作与数据架构加固

移除全 App 共用的保存忙碌锁，改为按操作身份隔离：同一弹窗只能提交一次，不同弹窗互不阻塞；当前弹窗保存时显示“保存中…”。卡片、大类、药品、用药安排、日期、排序和药品库“使用”不会再因其他操作尚未结束而变灰或丢失点击。数据库或规则校验失败时显示置顶“操作失败”弹窗；图片仍在读取时明确提示“图片正在读取，请稍后”。

药品档案、分隔条和用药记录删除统一收回 Repository 事务，界面不再直接写 DAO。卡片保存和排序同样在事务内执行；排序前验证完整成员关系，列表已变化或跨卡片排序时整次拒绝，避免只写入一部分。新增单操作防重复、不同编辑器并行、Repository 删除边界、旧列表排序拒绝及源码架构守卫测试。

## 1.0.38 分隔条与药品间距调整

分隔条按线条与中间文字的完整区域计算，与上方、下方药品的间距均由 6.5dp 调整为 5dp。保留透明背景、12sp 文字、自适应高度和长文字换行。

## 1.0.37 分隔条文字完整显示

分隔条保持透明，文字字号保持 12sp；取消固定 12dp 高度和单行裁切，改为最小 14dp、自适应高度及 14sp 行高，长文字可换行。药品到分隔条整个文字区域的上下间距继续保持 6.5dp。

## 1.0.36 分隔条整体间距统一

分隔条按“线条＋中间文字”整行计算，整行固定为 12dp；上方药品底部到分隔条整行顶部、分隔条整行底部到下方药品顶部均统一为 6.5dp，普通药品之间同样保持 6.5dp。同步压缩底部“添加项目 / 分隔条 / 排序”操作行与上一条目的距离。

## 1.0.32 分隔条保存修复

修复新增或编辑分隔条时，保存操作可能被页面共用的忙碌状态静默丢弃、点击“保存”无反应的问题。分隔条改用独立保存状态，保存期间显示“保存中…”并阻止重复提交；设备验收同时核对界面新增结果与数据库实际落库。

## 1.0.31 药品库使用准确归入大类

药品库左滑“使用”时，一日一次或两次改为直接选择便签内已有大类，药品会准确加入所选大类，不再把外层卡片误当作大类。移除服用时间为空时自动新建“药品”大类的回退；一日三次但未设置餐前/餐后时会明确提示设置。新增回归测试覆盖既有大类归位、选择数量不足及禁止默认大类生成。

## 1.0.28 更新按钮纵向对齐与状态色条（待发布）

更新按钮保持整个标题栏水平居中，同时与“用药便签”标题纵向居中对齐，不再贴近顶部。药品库移除当前使用绿点，改为卡片左侧低饱和浅绿色窄条；停用药品不显示色条，卡片保持原圆角且不增加描边。

## 1.0.27 主页面对齐与药品停用联动（已发布）

便签、药品库、用药时长的更新按钮固定在整个标题栏水平正中，便签页原有右侧操作按钮位置不变。药品库当前使用绿点移到规格前并降低饱和度，停用药品不显示状态标记。药品库当前使用条目支持左滑，以便签页已有的红色删除图标执行停用；确认后移除全部便签时段中的该药品、结束当前用药时长，同时保留药品档案和历史记录。

## 1.0.26 三模块更新按钮统一定位（已发布）

便签、药品库、用药时长三个主页面的更新按钮使用同一固定横向坐标，不再受标题字数及便签页右侧操作图标影响；药品库和用药时长为便签的两个右侧图标预留等宽空间。药品详情与编辑页仍不显示更新按钮。药品编辑中的“复用时带出的用量（可不填）”简化为“每次用量”，默认带入逻辑不变。药品库和用药时长统一按当前使用在前、停用在后稳定排序；药品库用绿点标记当前使用，停用不显示状态文字。用药时长卡片的药名改为灰色常规字重，日期和时长改为粗体，字号保持不变。

## 1.0.25 便签删除联动与模块入口修正（已发布）

便签内删除某个药品时，会同时删除当天所有卡片、所有时段中的同一药品，并重新安排受影响卡片的提醒；药品库资料和既有用药时长历史保留。底部四个入口始终保持原布局：便签页加号添加卡片，药品库和用药时长页加号均添加药品。药品库与用药时长双向使用同一份药品资料；从这两个页面新增药品都不会自动放进便签。便签新增药品会同步创建药品库资料和用药时长卡片。顶部更新按钮在便签、药品库、用药时长三个主页面均显示。药品库点药品直接进入编辑，不再经过资料中转页。发布改为仓库 Actions Secrets 保管原签名、由 `release/ready.json` 一键构建和发布，聊天环境不再需要持有本地签名文件。

精简用药时长卡片，移除重复的“开始日期 / 结束日期 / 时长”说明行及其占用空隙，日期和时长数值直接显示在药品名称下方。搜索、一药一卡、自动记录、历史时段和手动补录功能保持不变。
