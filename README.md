# MedReminder｜用药便签

Android 极简用药提醒与药品记录。白底浅色卡片，以药名和每次用量为视觉重点。

## V1.0 范围

- 自由结构：卡片 → 大类 → 条目。均可增删编辑和排序，不预设分类、卡片名称或提醒时间。
- 便签首页底部提供 40dp 圆角“一键更新并升级”，沿用浅蓝紫配色，直接下载并校验同签名新版，调起系统覆盖安装。
- 时间和规格可不填，留空隐藏。每个大类可设置一次每日提醒。
- 同一药品档案按名称与规格复用，首页条目独立保存用量。
- 创建药品自动入库，删除首页安排保留档案和多段使用日期。
- 本地图片导入应用私有目录，点击缩略图查看大图。
- 提醒通知显示当前大类的药名和用量，检查通知/精确闹钟权限，支持启动、升级、重启和时区变更后恢复。
- 两个主要页面：便签、药品库。无账号、打卡、OCR、统计和剂量建议。

## 构建

JDK 17、Android SDK 35、Gradle 8.9。

```sh
gradle :app:testDebugUnitTest :app:assembleDebug
gradle :app:connectedDebugAndroidTest
```

GitHub Actions 在每次 main 推送时构建，并在 API 28 和 API 35 模拟器上运行数据库、界面、真实闹钟通知测试。签名安装包由持有本地私钥的维护者构建；私钥不进入仓库或公开构建产物。Release 流程在验收任务通过后验证签名 APK、SHA-256 和源代码摘要并发布预发布版。没有签名包时仅产出构建 Artifact，不假称正式交付。

## 数据规则

六张 Room 表：cards、groups、items、medicines、periods、reminders。外键只从卡片向首页安排级联，药品历史独立于首页。删除药品档案前会确认，同时移除该药品的关联条目和历史。修改档案名称、规格或图片会同步所有引用；修改条目用量只影响该条目。使用状态由药品库的使用记录维护，移除首页安排不会擅自填写停用日期。

所有数据在本机，禁止破坏性数据库重建；后续升级必须提供 Room migration。卸载或清除数据会删除资料。自动系统备份关闭，无云同步。

## 提醒边界

清除最近任务不等于系统强行停止应用。Android 强行停止、关机、厂商电池限制可能阻止提醒。安装后需授予通知与精确闹钟权限，并在厂商设置允许后台运行/自启动。重启后首次解锁会恢复提醒。实体手机后台与长时间锁屏效果须实机验证。
