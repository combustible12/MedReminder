# MedReminder｜用药便签

Android 极简用药提醒与药品记录。白底浅色卡片，以药名和每次用量为视觉重点。

## V1.0 范围

- 自由结构：卡片 → 大类 → 条目。均可增删编辑和排序，不预设分类、卡片名称或提醒时间。
- 便签首页底部提供 40dp 圆角“一键更新并升级”，沿用浅蓝紫配色，直接下载并校验同签名新版，调起系统覆盖安装。
- 时间和规格可不填，留空隐藏。每个大类可设置一次每日提醒。
- 所有日期和时间均通过系统选择器设置，不提供格式文本框，不要求用户手动输入日期或时间。
- 同一药品档案按名称与规格复用，首页条目独立保存用量。
- 创建药品自动入库；便签首次加入药品自动开始一段用药记录，删除最后一条该药便签时自动结束，停药后再次添加会保留旧时段并新建记录。
- 便签删除一个药品时，会同时删除全天其他时段的同一药品并结束当前用药时段；药品库档案和既往时长记录保留。
- 本地图片导入应用私有目录，点击缩略图查看大图。
- 提醒通知显示当前大类的药名和用量，检查通知/精确闹钟权限，支持启动、升级、重启和时区变更后恢复。
- 三个主要模块：便签、药品库、用药时长。用药时长支持按药名搜索，一个药品一张卡片，并可补录早期使用记录。无账号、打卡、OCR和剂量建议。
- 右下角加号随模块变化：便签添加卡片，药品库添加药品，用药时长不显示加号。便签新增药品会同步进入药品库和用药时长；药品库新增药品只同步到用药时长，不会自动加入便签。

## 构建

JDK 17、Android SDK 35、Gradle 8.9。

```sh
gradle :app:testDebugUnitTest :app:assembleDebug
gradle :app:connectedDebugAndroidTest
```

GitHub Actions 在每次 main 源码推送时构建，并在 Android 16 模拟器上运行数据库、界面和提醒测试。正式发布由独立的 Publish MedReminder 工作流完成：永久签名材料仅保存在 GitHub Actions Secrets，release/ready.json 绑定源码提交与版本；工作流重新运行 JVM/Android 测试编译、构建签名 APK、核对固定证书、验证旧版覆盖安装和启动，再生成 update.json 并发布 GitHub Release。发布不依赖本地电脑或 Work 环境，私钥不进入仓库和构建产物。

## 数据规则

七张 Room 表：cards、groups、items、medicines、periods、reminders、dividers。外键只从卡片向便签安排级联，药品档案和历史独立保存。删除药品档案前会确认，同时移除该药品的关联条目和历史。修改档案名称、规格或图片会同步所有引用；修改条目用量只影响该条目。用药状态以该药是否仍存在于任一便签为准，药品库资料编辑不会改变使用时段。

所有数据在本机，禁止破坏性数据库重建；后续升级必须提供 Room migration。卸载或清除数据会删除资料。自动系统备份关闭，无云同步。

## 提醒边界

清除最近任务不等于系统强行停止应用。Android 强行停止、关机、厂商电池限制可能阻止提醒。安装后需授予通知与精确闹钟权限，并在厂商设置允许后台运行/自启动。重启后首次解锁会恢复提醒。实体手机后台与长时间锁屏效果须实机验证。
